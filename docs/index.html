How the comparison is measured
  • Rules: deterministic BM25-style keyword scoring over titles and policy text, up to three extracts; no LLM.
  • Full context: all 98 records are supplied to the LLM for every question. No vector index.
  • Vector retrieval: a saved exact cosine-similarity index of learned policy embeddings supplies the five nearest records to the same LLM.
  • LLM prompts, model and settings are identical; only the supplied records differ. Method order rotates between benchmark questions.
  • Response time includes retrieval, network calls and answer validation, excluding one-time index preparation. Only provider-reported tokens are recorded; unknown embedding tokens remain unknown.
  • One run per question is a small descriptive experiment, not a statistical estimate of long-run reliability. The questions and expectations were AI-assisted and need student review.
  • A valid citation is a source check, not proof that all claims in an answer follow from that source.
